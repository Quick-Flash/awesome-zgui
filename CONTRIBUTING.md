# Contribution Guidelines

Open a pull request that adds one entry per line, in the matching section.

## Entry format

```markdown
- [Name](https://link) - Short description ending with a period.
```

## Rules

- Project must use zgui and be publicly available.
- Keep descriptions short and factual. No marketing language.
- Keep entries in each section sorted alphabetically.
- Check spelling and links before submitting.
- New sections need at least two entries.
- Mention the zgui revision or fork in the description only when it matters to users.
